# Assessment Builder – React Practice

A step-by-step recreation of an Assessment Builder application using React, with a focus on understanding React fundamentals and applying concepts from the official React documentation.

## About the Project

This project is being developed as a practical learning exercise to understand how React applications work.

Rather than simply building a UI, the goal is to understand component architecture, state management, props, event handling, and how different parts of a React application communicate with each other.

The application allows users to create and configure assessments through a multi-step workflow.

## Tech Stack

- **React** – Building reusable UI components
- **JavaScript (ES6+)** – Application logic
- **Vite** – Development environment and build tool
- **CSS** – Styling and layout

## Getting Started

### 1. Clone the repository

```bash
git clone https://github.com/abdularshad080-dev/react_practice.git
```

### 2. Navigate to the project directory

```bash
cd react_practice
```

### 3. Install dependencies

```bash
npm install
```

### 4. Start the development server

```bash
npm run dev
```

Open the local URL provided by Vite in your browser.
